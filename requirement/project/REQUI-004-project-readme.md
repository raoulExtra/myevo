# Project README

Every project MUST provide a root-level `README.md` file that identifies the project and explains its purpose, structure, and primary verification commands.

## Acceptance criteria

- **REQUI-004-ACC-001** — A root-level `README.md` file exists.
- **REQUI-004-ACC-002** — The README identifies the project and states its purpose.
- **REQUI-004-ACC-003** — The README describes the primary project directories and executable verification commands.
- **REQUI-004-ACC-004** — The README is maintained as Markdown source in the project repository.
- **REQUI-004-ACC-005** — The README documents the approved placement of executable project code and Markdown records.
- **REQUI-004-ACC-006** — The README documents the project test phases from planning through commit.
